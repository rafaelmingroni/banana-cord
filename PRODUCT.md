# Mingrx

<!-- impeccable:product-schema 1 -->

This product record governs work on the public website mingrx.site. The Windows application is the product being presented; its capabilities constrain what the website may claim.

## Platform

web

## Users

Friends and small groups who use or are considering Mingrx for private messages, communities, voice calls, camera and screen sharing. Some visitors arrive on a phone although the available application is for Windows.

## Product Purpose

Present the actual application, provide the official Windows download, route community invitations to the installed application or download, and help visitors find support and privacy information.

## Positioning

Undecided. Rafael explicitly confirmed that Mingrx does not yet have a defined differentiator. Do not invent competitive superiority, measured performance, adoption, testimonials, or privacy guarantees to create one.

## Operating Context

The current app is distributed through GitHub Releases with automatic updates. An account uses email and password with email verification. Community links use mingrx.site and the mingrx:// protocol. Support and privacy contact is mingrxapp@gmail.com; the responsible maintainer is Rafael Mingroni.

## Capabilities and Constraints

- Free Windows application; no paid offering, subscription, refund flow, browser client or phone application is currently presented.
- Private messages, communities, text/voice channels, camera and screen sharing are existing capabilities.
- New private messages between compatible clients use end-to-end encryption; community-channel messages and metadata do not have the same protection. Preserve the actual limitations.
- Existing website is static HTML/CSS/JavaScript on GitHub Pages with the custom domain mingrx.site. This redesign has not requested a framework or hosting migration.
- User selected a redesign of the complete website, including homepage, invitations and support. Legal pages need coherent presentation while preserving verified facts.
- Public version naming follows AGENTS.md; public 3.2 uses technical SemVer 3.2.0 in installers/updater metadata.

## Brand Commitments

- Use Satoshi for the website typography, explicitly requested by Rafael.
- Preserve the Mingrx name and existing recognizable logo.
- Preserve a dark presentation. The user rejected a white website and now finds the current composition too simple and conservative.
- Avoid purple gradients, pill buttons, fabricated reviews/counts/metrics, fake AI portraits, excessive animation, cursor effects and vague promises.
- Solid brand violet is present in the logo and application; it has not been prohibited.
- Pinterest board supplied as inspiration, not as an instruction to copy another brand: https://br.pinterest.com/en_juliao/sites-modernos/.

## Evidence on Hand

- Actual application source and release notes in the repository.
- `site/assets/mingrx-private.webp`: genuine capture of Mingrx 3.1.10 using a demonstration account, without real conversations. Do not relabel it as a newer release without producing a new capture.
- New demonstration scenes must use the actual app and clearly identified demonstration content. Unverified mockups must not be presented as shipped functionality.
- No confirmed testimonials, adoption counts, comparative benchmarks or independent performance claims have been provided.

## Product Principles

- Demonstrate real capabilities before making claims.
- Keep the path to download, join a community and obtain help understandable.
- Preserve invitation compatibility, official download origins and automatic updating.
- Make visual character distinctive without fabricating product differentiation.
- Collect and expose only information needed for the task.

## Accessibility & Inclusion

Preserve keyboard navigation, visible focus, readable contrast, meaningful image alternatives and responsive layout. A modern visual presentation must also be usable on phones, even though the downloadable app is Windows-only.
